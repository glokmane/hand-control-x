# Hand Control X

**Управление компьютером жестами руки и голосом — нужна только веб-камера.**

Hand Control X превращает обычную камеру в мышь, пульт и игровой контроллер.
Курсор двигается вместе с ладонью, щипок заменяет клик, знак «V» — прокрутку,
а голосом можно запускать программы, менять громкость и управлять браузером.
Сверху — мини-игры, в которых руки заменяют джойстик.

## Возможности

- **Управление курсором** — двигаете руку, курсор сдвигается как мышь с заданным DPI
  (1 дюйм движения руки = DPI пикселей).
- **Клики, перетаскивание, прокрутка** — жестами, без дополнительного железа.
- **Одна «своя» рука** — программа запоминает руку, которой начали управлять,
  и не реагирует на руки других людей в кадре.
- **Офлайн-голос по-русски** — [Vosk](https://alphacephei.com/vosk/) работает локально:
  без облака и аккаунтов.
- **Управление браузером голосом** — поиск, вкладки, ссылки, прокрутка, диктовка, полный экран.
- **Управление Windows голосом** — запуск программ, окна, рабочие столы, громкость,
  яркость, заряд батареи, скриншоты, блокировка/сон/выключение с подтверждением.
- **Яндекс.Музыка** — следующий/предыдущий трек, перемотка, «что играет»,
  даже если вкладка в фоне, а браузер свёрнут.
- **Игры руками** — 3D-дартс, дуэль джедаев от первого лица и демо с эмоциями и мемом «67».
- **Модели скачиваются сами** — MediaPipe и Vosk подтягиваются при первом запуске.

## Установка (Windows)

```powershell
git clone https://github.com/glokmane/hand-control-x.git
cd hand-control-x

python -m venv .venv
.\.venv\Scripts\activate

pip install -r WIN\hand_control\requirements.txt
```

> При первом запуске приложение скачает `hand_landmarker.task` (~8 МБ),
> `face_landmarker.task` (~4 МБ) и русскую модель Vosk (~50 МБ).

## Запуск

Все команды выполняются из папки `WIN\hand_control`.

| Скрипт | Что делает |
|---|---|
| `python hand_control.py` | **Основное приложение** — жесты + голос |
| `python voice_browser.py` | Только голос, без камеры |
| `python darts_game.py` | 3D-дартс с управлением рукой |
| `python jedi_duel.py` | Дуэль джедаев от первого лица |
| `python emotion_67.py` | Эмоции по лицу + мем «67» |
| `python voice_windows.py` | Голосовые действия Windows (работает и отдельно) |

## Жесты

| Жест | Действие |
|---|---|
| Открытая ладонь | Движение курсора |
| Кулак | «Поднять мышь» — курсор стоит, руку можно переставить |
| Большой + указательный (ОК) | Левый клик: коснулись и отпустили — клик, коснулись и повели — перетаскивание |
| Большой + средний | Правый клик |
| Большой + безымянный | Двойной клик |
| Указательный + средний (V) | Прокрутка-джойстик: чем дальше от точки, где показали V, тем быстрее листается |

При щипке остальные пальцы держите поднятыми (как знак ОК) — так щипок не путается с кулаком.

**Клавиши в окне камеры:** `P` — пауза · `L` — выбрать руку заново · `Q` / `Esc` — выход.

## Голосовые команды

Скажите **«команды»** — на экране появится полный список. Кратко:

### Система (Windows)

| Скажите | Результат |
|---|---|
| `запусти телеграм` | Запуск любой установленной программы через поиск Windows |
| `открой проводник / блокнот / калькулятор / параметры` | Проводник / Блокнот / Калькулятор / Параметры |
| `открой папку загрузки / документы / рабочий стол` | Открыть известную папку |
| `сверни окно`, `разверни окно`, `закрой программу` | Управление окнами |
| `окно влево` / `окно вправо`, `следующее окно` | Прикрепить / переключить окно |
| `новый рабочий стол`, `следующий рабочий стол` | Виртуальные столы |
| `громкость 40`, `громкость на максимум`, `громче`, `тише` | Звук |
| `яркость 70`, `ярче`, `темнее` | Яркость |
| `который час`, `какое сегодня число`, `заряд батареи` | Ответ голосом |
| `скриншот области`, `буфер обмена`, `смени язык` | Полезные действия |

| `выключи компьютер`, `перезагрузи компьютер` | Переспросит («да»), отложит на 60 с, `отмени выключение` отменяет |

### Браузер

| Скажите | Результат |
|---|---|
| `найди рецепт борща`, `найди на ютубе котиков` | Поиск в интернете / на YouTube |
| `открой ютуб`, `открой в новой вкладке википедию` | Открыть сайт |
| `нажми войти` | Найти текст на странице и нажать |
| `назад`, `вперёд`, `обнови`, `стоп` | Навигация |
| `новая вкладка`, `закрой вкладку`, `вкладка три` | Вкладки |
| `вниз`, `вверх`, `в начало`, `в конец` | Прокрутка |
| `увеличь`, `уменьши`, `полный экран`, `найди на странице ...` | Страница |
| `напечатай ...`, `диктовка`, `ввод`, `выдели всё` | Ввод текста и диктовка |
| `пауза` / `играй`, `громче`, `тише`, `без звука` | Видео и звук |

### Жесты и голос вместе

`сменить руку`, `выключи жесты` / `включи жесты`, `изменить ди-пи-ай` + число
от 400 до 2500 (например, `изменить ди-пи-ай тысяча`).

### Яндекс.Музыка

`следующий трек`, `предыдущий трек`, `перемотай вперёд`, `перемотай назад на 30 секунд`,
`трек сначала`, `останови музыку`, `включи музыку`, `что играет`, `открой яндекс музыку`.
Работает и когда вкладка в фоне, а браузер свёрнут.

## Игры

**Дартс** — открытой ладонью наводите прицел, щипком берите дротик, затем резко взмахните
рукой вверх и разожмите пальцы — бросок. 5 раундов по 3 дротика.
Клавиши: `M` — камера/мышь · `R` — заново · `Esc` — выход.

**Дуэль джедаев** — правая рука держит световой меч (кулак как рукоять): наклон кисти задаёт
угол клинка, блок — клинок поперёк удара, парирование — резкое встречное движение,
атака — взмах, когда противник рядом. Левая рука — Сила: толчок (ладонь вперёд),
притяжение (ладонь или кулак назад), удушение (держать знак ОК), вырвать меч
(держать раскрытую ладонь ~0,6 с, затем сжать кулак).
Клавиши: `M` — камера/мышь · `X` — поменять руки · `H` — призрак удара · `Tab` — справка ·
`R` — заново · `Esc` — выход.

**Эмоции 67** — MediaPipe Face Landmarker читает 52 параметра мимики и выбирает смайлик
(смеюсь, радость, грусть, удивление, злость, подмигиваю, поцелуй, сплю). Первые 2 секунды —
калибровка: смотрите в камеру с нейтральным лицом. Двигайте обеими руками вверх-вниз
попеременно — появятся руки, показывающие «67».
Клавиши: `C` — перекалибровать · `Esc` / `Q` — выход.

## Если что-то не работает

| Проблема | Решение |
|---|---|
| `Cannot open camera` | Закройте приложения, которые уже держат камеру (Zoom, Teams, OBS): камеру может занять только один процесс. |
| Не скачивается модель | Проверьте интернет и прокси; модели берутся с `storage.googleapis.com` и `alphacephei.com`. |
| Не распознаются команды | Разрешите микрофон в настройках приватности Windows, говорите чуть медленнее, закройте другие программы, которые пишут звук. |
| Курсор слишком быстрый / медленный | Скажите `изменить ди-пи-ай` + число или отредактируйте `hand_settings.json`. |
| `ModuleNotFoundError` | Активируйте виртуальное окружение и переустановите `requirements.txt`. |
| Низкий FPS | Закройте фоновые программы: MediaPipe работает на CPU. |
