# Hand Control X + AI — инструкция (Windows 10/11)

В этой сборке добавлен AI-слой поверх существующего голосового управления.
Старые команды продолжают обрабатываться старым парсером. Фразы, которые он
не распознал, передаются LLM. Жестовое управление и обработка камеры не меняются.

## Что добавлено

- `ai_assistant.py` — AI-агент, адаптеры OpenAI-compatible API, каталог инструментов.
- `ai_settings.example.json` — пример настроек.
- Изменён `voice_browser.py` — передача неизвестных команд AI в отдельном потоке.
- Дополнены зависимости в `requirements.txt`.

Инструменты агента ограничены allowlist: запуск приложения, громкость, яркость,
поиск в браузере, открытие HTTP/HTTPS сайта, вставка текста, чтение активного
окна, управление Яндекс Музыкой и работа с файлами: create_folder, open_folder,
list_folder, create_text_file. Пути для файловых инструментов разрешены только
внутри профиля пользователя (рабочий стол, документы, загрузки...), системные
папки заблокированы, удаления среди инструментов нет. Модель не может выполнять произвольный Python,
PowerShell, удалять файлы, выключать ПК, отправлять сообщения или совершать покупки.

## 1. Подготовка Python

Рекомендуется Python 3.10 или 3.11 (совместимость MediaPipe зависит от версии).
Открой PowerShell в папке `WIN\hand_control` и выполни:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Если Windows запрещает активацию окружения, выполни в этом окне:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

## 2. Настройка DeepSeek API (Быстро и качественно)

DeepSeek отвечает за 1–2 секунды (в отличие от 30–40 с на процессоре) и отлично понимает русский язык.

1. Получи ключ на https://platform.deepseek.com/api_keys
2. Укажи его в `ai_settings.json`:
   ```json
   "provider": "deepseek",
   "deepseek": {
     "api_key": "sk-твой-ключ-deepseek"
   }
   ```
   Либо сохрани в переменную среды:
   ```powershell
   setx DEEPSEEK_API_KEY "sk-твой-ключ-deepseek"
   ```

## 3. Настройка других провайдеров (OpenAI / Ollama)

- **OpenAI**: установи `OPENAI_API_KEY` и выбери `"provider": "cloud"`.
- **Локальная Ollama**: установи Ollama, скачай модель (`ollama pull qwen2.5:latest`), выбери `"provider": "local"`.
- **Режим auto** (`"provider": "auto"`): сначала проверяет ключ DeepSeek, затем OpenAI, а если ключей нет — автоматически переключается на локальную Ollama.

## 4. Озвучка ответов (TTS)

- **Из коробки**: используется встроенный голос Windows (Microsoft Irina). Дополнительно ничего ставить не нужно.
- **Живой нейросетевой голос (как у Алисы)**: если хочешь максимально реалистичную речь, установи `edge-tts`:
  ```powershell
  pip install edge-tts
  ```
  Программа автоматически подхватит его и начнет озвучивать ответы живым голосом `ru-RU-SvetlanaNeural`.
- Чтобы выключить озвучку, поставь `"speak_responses": false` в `ai_settings.json`.

## 5. Запуск

Из папки `WIN\hand_control`, с активированным виртуальным окружением:

```powershell
python hand_control.py
```

Это запускает камеру, управление жестами и голос. Если нужен только голос:

```powershell
python voice_browser.py
```

### Как общаться с LLM:
1. **Голосом**:
   - Скажи обычную существующую команду, например «громкость 40», «сверни окно», «открой ютуб» — её мгновенно выполнит локальный парсер.
   - Скажи любую свободную фразу, вопрос или обращение к AI, например:
     - «Привет, как дела?»
     - «ИИ, расскажи анекдот»
     - «Сколько километров до Луны?»
     - «Поставь чувствительность мыши 1400» (AI использует инструмент `set_dpi`)
     - «Поставь жесты на паузу»
   - AI ответит вслух (русский голос Windows), напечатает ответ в консоли и аккуратно выведет его в виде субтитров прямо поверх кадра камеры.

2. **Текстом в окне камеры**:
   - В окне камеры нажми клавишу **C** (Chat).
   - Откроется окно ввода сообщения, куда можно напечатать любой вопрос или команду. AI ответит голосом, текстом в консоль и на экран камеры.

## 6. Важные ограничения и безопасность

- Модель получает только распознанный Vosk текст, а не аудиозапись.
- Анализ скриншотов/экрана не включён.
- Камера и жесты не передаются LLM.
- Вставка текста происходит в активное окно — перед такой командой проверь фокус окна.
- Не диктуй пароли, токены и другие секреты в AI.
- Неизвестные фразы могут отправляться в облако, если выбран cloud/auto и задан ключ.
- Для приватного режима выбери `local`.
- Сложные действия выполняются ограниченным числом шагов (`max_steps`).
- Если локальная модель не поддерживает tool calling, выбери другую совместимую модель.

## 7. Если AI не отвечает

1. Проверь, что `ai_settings.json` лежит рядом с `voice_browser.py`.
2. Для cloud: открой новое окно PowerShell и проверь `echo $env:OPENAI_API_KEY`.
3. Для local: проверь, что Ollama запущена и `ollama list` показывает модель.
4. Посмотри текст ошибки в консоли программы.
5. Убедись, что команда не совпала с существующим парсером: он всегда имеет приоритет.
